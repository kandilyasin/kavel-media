# KAVEL Thenics – Medien

Öffentliche Medien für die App **KAVEL Thenics** (3D-Übungsanimationen als animiertes WebP).

- `exercises/<übung>.webp` – 480 × 480, Endlosschleife
- Versionen werden als Git-Tag veröffentlicht (`v1`, `v2`, …). Die App lädt eine feste Version:
  `https://cdn.jsdelivr.net/gh/kandilyasin/kavel-media@v1/exercises/<übung>.webp`

Neue oder geänderte Animationen: Dateien ergänzen, neues Tag (z. B. `v2`) anlegen und
`ExerciseMedia.version` in der App anpassen.
